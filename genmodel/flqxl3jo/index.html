条件和边缘概率路径

流匹配的第一步是找到一个概率路径，直观感觉概率路径指明了噪声点到真实数据的一个插值路径。

我们定义的ODE 轨迹，满足X0∼pinit,t=0X_0 \sim p_{init},t = 0X0​∼pinit​,t=0以及X1∼pdata,t=1X_1 \sim p_{data},t = 1X1​∼pdata​,t=1。 但是当0<t<10 < t < 10<t<1时会发生什么？，这中间的空档实际上可以自由发挥了，这期间的路径，在数学上可以被称为概率路径。

下面介绍一些新的内容，对于数据点 z∈Rdz \in \mathbb{R}^dz∈Rd，我们用 δz\delta_zδz​ 表示 狄拉克δ\deltaδ（Dirac delta）“分布”。这是可以想象的最简单的分布：从 δz\delta_zδz​ 中采样总是返回 zzz（即它是确定性的）。条件（插值）概率路径（Conditional (interpolating) probability path）是一组在 Rd\mathbb{R}^dRd 上的分布 pt(x∣z)p_t(x|z)pt​(x∣z)，使得：

p0(⋅∣z)=pinit,p1(⋅∣z)=δzfor all z∈Rd.p_0(\cdot|z) = p_{\text{init}}, \quad p_1(\cdot|z) = \delta_z \quad \text{for all } z \in \mathbb{R}^d. p0​(⋅∣z)=pinit​,p1​(⋅∣z)=δz​for all z∈Rd.

换句话说，一个概率路径，将初始化分布，转变成了一个单个数据点（高维空间里的一个“点”）。你可以把概率路径理解成空间中的一条轨迹。
